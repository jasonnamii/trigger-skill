# 트리거 사전 — 정의 + 절차

> 28 정식명 + 9 콤보. 단어 등장 시 해당 절차 수행.
> 출처: V9 마스터 메모리 + portable + 형 직접 정의

---

## A. 분석 트리거

### 홈즈
세밀관찰 → 이상징후 탐지 → 복수가설 생성 → 증거대조 검증 → 결론도출 + 추론경로

### 오컴
경쟁가설 병렬 → 설명력 비교 → 가정 최소 가설 채택 + 기각 사유

### 제1원리
유추·관행 차단 → 환원 불가한 자명 명제까지 분해 → 바닥부터 재조립

### 베이지안
사전확률 명시 → 새 증거 강도 반영 → 사후확률 갱신 (확률표 + 갱신 근거)

### 엄브렐러
주어진 요소 → 절대자 확장(동류 전수) → MECE 분류 → 상위 개념 명명 (우산도)

### 아날로지
구조적 패턴 추출 → 타 도메인 성공사례 매핑 → 적용 가능성 검증 (매핑표 + 적용안)

### 연역수렴
L1: 축별 독립 연역 (원칙→적용→예외)
L2: 축간 교차 연역 (모순·강화·빈자리)
산출: 축별 통찰 + 교차 통찰 + 추가 조사 영역

---

## B. 구조 트리거

### 외과적 (서지컬)
부분 수정 시 전체 MECE 구조 완전 유지 + 수정 범위 최소화 + 정합성 검증

### 백본
챕터(1뎁스) 단위로 적용 — 각 챕터 결론 먼저 → 역방향 추론 → 필수 논거만. 챕터 간 서사 흐름 유지로 백본만 읽어도 전체 서사가 잡히게

### 스켈레톤
군더더기 전부 제거 → 가장 심플한 논리 흐름만 (골격도)

### SHE
**Shrink**(핵심만 압축, 수식·중복·우회 제거) → **Hide**(삭제 ✗ 은닉, 복원가능 형태로 보존, 비가역 삭제 금지) → **Embody**(추상 과잉 방지, 구체적 행동·수치·예시로 체화). 순서 S→H→E

### 엘베피치
30초 제약 → 코어 1문장 → 2~3문장 재조립 (30초 피치)

### 타임스톤
인과·선후관계 파악 → 시간축 정렬 → 순서 교정 (교정된 시퀀스)

---

## C. 실행 트리거

### 맥가이버
제약조건 파악 → 가용자원 탐색·재해석 → 비표준 용도 발견 → 창의적 조합 → 즉시 실행

### 넛지
강제 없이 선택설계로 자연스럽게 행동 유도. 선택 자유 보존 + 디폴트·프레이밍 설계 + 의도 방향 유도

### 제출청소
외부 제출용 문서 정제. 내부 흔적 제거, 콘텐츠 불변. **13축 체크리스트 → `references/protocol-cleanup.md` 풀버전**

### 작업설계자
대화 맥락 기반 목표 재구성 + 실행 계획 설계. 7단계 출력 후 **멈추고 승인 대기**. 항목 1~2문장, 추상 금지. **풀버전 → `references/protocol-designer.md`**

## D. 판단 트리거

### 프리모르템
실패 확정 전제 → 역추적 → 치명 원인 Top 3 → 사전 차단책

### 트리아지
자원 제약 전제 → 긴급×중요 2축 → 즉시/예약/위임/제거 → 시퀀싱 (우선순위 매트릭스)

### 핑퐁 (컨펌 게이트)
①대화 지속 의지 선언 ②질문·의견 대기 ③답변만, 실행 금지 ④컨펌 시에만 다음 턴 실행
**컨펌 없이 실행 = FAIL**

### 리허설 (컨펌 게이트)
①사용자 의견·상담 수집 ②적용 결과 미리보기 출력(dry-run) ③변경점 highlight ④컨펌 대기
**컨펌 없이 실제 실행 = FAIL**

### 작업계획 (컨펌 게이트)
①Before/After 비교 ②갭 분석 ③타임라인 정렬 ④상담 반영 계획 ⑤컨펌 대기
**컨펌 없이 실행 = FAIL**

## E. 관점 트리거

### 줌
미시 ↔ 거시 스케일 선택 → 개인/팀/조직/산업/사회 재조명 (스케일별 관점)

### 절대자
①**목표 선언**(필수)
②**입력 팩터 수집**
③**목표 기준 MECE 너비확장** — 팩터 상하위 자동 재배치, 누락 동류 추가
④**수평적 복수 엄브렐러 청킹·명명**
⑤**각 엄브렐러 하위 드릴다운 위임** — 깊이확장 ✗ 너비확장 ✓
산출: 목표 + 수평 엄브렐러 N개 + 각 엄브렐러 MECE 하위 팩터

> 핵심 사상: 어떤 사안의 완전한 정답·전체상을 아는 가상 존재가 있다고 전제 → 빠진 부분 탐색하여 완전해에 수렴 → 너비로 펼친다 (위로 파지 않고 옆으로)

### 틀밖
①프레임 식별 (대상에 박힌 전제·용도·경계·카테고리 명시)
②프레임 박제 후 거부 (왜 이 프레임? 누가·언제·왜 만들었나? 누구 이득?)
③3대 킬샷:
  (a) 진짜 답이 "이걸 안 하는 것/안 쓰는 것" 아닌가
  (b) 대상·구조·방식 자체를 바꿔야 하지 않나
  (c) 아무도 안 묻는 질문은?
④프레임 밖 답 없으면 "프레임 안 유효" 명시 후 종료

## F. 전환 트리거

### 부작업

### 주작업
스냅샷 복원 → TodoList 로드 → 중단 지점 재개 (주작업 복귀)

## H. 콤보 트리거

콤보명 등장 = 구성 트리거 전부 순차 실행. 순서: 관점 → 분석 → 구조 → 판단 → 실행

| 콤보 | 구성 | 상황 |
|------|------|------|
| 미궁 | 백본 → 제1원리 | 방향 상실 |
| 마비 | 트리아지 → 홈즈 | 할 일 많아 시작 불가 |
| 시야 | 줌 → 절대자 → 엄브렐러 | 시야 협소 |
| 벽 | TRIZ → 오컴 | 트레이드오프 돌파 불가 |
| 카드없음 | 맥가이버 → TRIZ | 자원·수단 부재 |
| 장밋빛폭주 | 프리모르템 → 홈즈 | 낙관 과잉 |
| 제출직전 | 스켈레톤 → 제출청소 | 납품 직전 점검 |
| 복잡계 | 연역수렴 → 줌 | 변수 많아 수렴 불가 |
| 박스 | 틀밖 → 제1원리 | 프레임 의심 후 환원 재구성 |

## I. 공통 규칙

- **복합 순서:** 2개↑ 트리거 동시 등장 시 **관점 → 분석 → 구조 → 판단 → 실행** 순서
- **유사 트리거 노출:** 발동 시 응답 상단 1줄로 "🔗 유사: A · B · C" (2~3개 상한)
- **컨펌 게이트:** 핑퐁·리허설·작업계획 3종은 실행 전 정지. "go/실행/진행/ok" 명시 컨펌 후에만 다음 턴
- **기억 재구성 금지:** 트리거 단어 등장 시 반드시 이 문서 참조. 기억으로 재구성 = FAIL
